核心邏輯

診斷由外而內，訓練由內而外。 掉速、腿沉、換氣亂、划次增加是表象；先找平衡、節奏、水感、支撐與協調，再處理表面動作。

Effortless｜省力
先減阻、放鬆、水平身體。

Efficient｜效率
同速更少無效動作、速度更穩。

Enduring｜耐力
動作品質延長，再把速度加上去。

泳力・CSS・配速換算

只填你有的距離即可。CSS 用 400m 與 200m TT；泳力用書中泳力表的可見錨點做分段插值。

CSS

CSS 秒/100m = (400m 秒數 − 200m 秒數) ÷ 2

例：8:00 與 3:45 → (480−225)/2 = 127.5 秒 → 2:07.5/100m。

泳力

把不同距離換到共同尺度，目的不是貼標籤，而是選課表速度與負荷。不同距離泳力落差也能看出「速度型 vs 耐力型」差異。

如何解讀 100 次訓練

速度趨勢

裸游平均配速是否下降；同時檢查是否只是短距離比例變高。

效率趨勢

SWOLF、DPS、心率效率是否改善；要在相似泳姿與器材條件下比較。

轉換趨勢

Agility / 蛙鞋 / 腰間挖水器後的裸游是否逐漸接近器材速度。

長期判斷原則：不要只看單一最好成績。優先看最近 10 次、30 次、100 次的移動趨勢，並把裸游、器材、Drill 分開比較。

來源與方法

此工具將教材與公開資料轉成摘要、計算、診斷與課表邏輯，不逐字重製整本書或網站。
