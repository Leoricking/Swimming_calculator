核心邏輯

診斷由外而內，訓練由內而外。 掉速、腿沉、換氣亂、划次增加是表象；先找平衡、節奏、水感、支撐與協調，再處理表面動作。

Effortless｜省力
先減阻、放鬆、水平身體。

Efficient｜效率
同速更少無效動作、速度更穩。

Enduring｜耐力
動作品質延長，再把速度加上去。

泳力・CSS・配速換算

只填你有的距離即可。CSS 用 400m 與 200m TT；泳力用書中泳力表的可見錨點做分段插值。

CSS

CSS 秒/100m = (400m 秒數 − 200m 秒數) ÷ 2

例：8:00 與 3:45 → (480−225)/2 = 127.5 秒 → 2:07.5/100m。

泳力

把不同距離換到共同尺度，目的不是貼標籤，而是選課表速度與負荷。不同距離泳力落差也能看出「速度型 vs 耐力型」差異。

六區泳速

CSS／臨界泳速測試中心

把書中的「臨界游速」轉成可直接測試、計算、追蹤與排課的工具。

這就是 CSS 嗎？

概念上高度相近。 書中的「臨界游速 Critical Swimming Speed / Critical Velocity」與現在常用的 CSS， 都是在估計「可長時間維持、接近乳酸閾值的游泳速度」。

書中用 400m 與 200m 的粗略公式： 速度 = (400−200) ÷ (T400−T200)。 換成 CSS 秒/100m，正好等價於： CSS = (T400−T200) ÷ 2。

差別：書中還介紹「多距離時間－距離回歸線」求斜率，這是較精細的 Critical Speed； SwimLab 原本的 CSS 則是 400/200 兩點法。兩者可同時保留，不要混成同一個數字。

臨界泳速測試計算器

測試方式

① 測試前 2 天

避免激烈訓練，讓測試反映當下真實能力，而不是疲勞。

② 同一週完成

盡可能在同一週完成各距離測試，減少體能狀態差異。

③ 中短距離

25 / 50 / 100 / 200 / 400m 可在同一天測。充分熱身後，建議先長後短。

④ 長距離

800m、1500m 建議分開到其他天測，避免前一個長距離干擾下一個。

⑤ 每一項都盡力

測驗本身是能力測試，不是一般有氧課；每個距離要接近當日最佳表現。

⑥ 時間有限時

書中建議可用 50 / 100 / 200 / 400m 四個點作圖；SwimLab 也可用任意 ≥2 點回歸。

實務建議：若目的只是快速更新 CSS，可做 400m + 200m TT； 若要分析速度型／耐力型與長距離能力，使用 4–7 個距離的回歸會更完整。

如何讀臨界速度圖

斜率＝臨界速度

以距離為 Y、時間為 X 做線性回歸，趨勢線斜率就是 m/s 的臨界速度。

截距＝短距離／無氧特性線索

書中用截距與斜率一起觀察有氧與無氧能力的變化。不要只看 50m PB。

核心理念：「變快」不能只看短距離 PB。50m 變快、但 400 / 800m 變慢，可能只是爆發力提升； 真正整體進步應看臨界速度是否提高，以及相同速度能否維持更久。
來源頁面數字提醒：你提供的頁面圖上標示約 1.035 m/s，但若直接用同頁表格的 25 / 50 / 100 / 200 / 400 / 800 / 1500m 成績做線性回歸，結果約為 1.014 m/s。 SwimLab 不強行校正成書圖數字，而是以實際輸入成績重新計算。

用臨界速度做間歇訓練

來源頁面的核心原則是：一次只調整一個變數，穩定 2 週以上再進下一階段。

調整 1｜增加趟數

先維持同一到岸時間與同一出發週期，再逐步增加趟數。

例：100m ×8 → ×10 → ×12 → …；若後段明顯掉速則退回。

調整 2｜縮短休息

到岸時間先不變，逐步縮短出發週期，訓練快速恢復。

例：2:00 出發 → 1:55 出發；先維持數週再繼續。

調整 3｜增加距離

把 100m 間歇延長到 200m 等更長距離，重點仍是均速與技術穩定。

書中示例用 200m 間歇作為另一種速度耐力刺激。

調整 4｜縮短到岸時間

耐力基礎穩定後才真正提高目標速度；回到原出發週期，但每趟游得更快。

一次只改一個變數，不要同時加量、縮休息又加速。
停止條件：若到岸時間明顯偏離目標、連續多趟掉速，或技術開始崩， 應減少趟數／延長休息，而不是硬撐。

多久重新測一次？

書中建議持續做間歇時可定期重新測臨界游速；頁面範例提到約每兩個月重新測量一次。 SwimLab 建議把它當成 6–8 週訓練週期的檢查點，並與 Garmin 長期趨勢一起看。

如何解讀 100 次訓練

速度趨勢

裸游平均配速是否下降；同時檢查是否只是短距離比例變高。

效率趨勢

SWOLF、DPS、心率效率是否改善；要在相似泳姿與器材條件下比較。

轉換趨勢

Agility / 蛙鞋 / 腰間挖水器後的裸游是否逐漸接近器材速度。

長期判斷原則：不要只看單一最好成績。優先看最近 10 次、30 次、100 次的移動趨勢，並把裸游、器材、Drill 分開比較。
